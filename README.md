# ConnectHub – Mini Social Media Platform

ConnectHub is a mini social media web application developed as part of an internship task. It aims to provide a simple and interactive platform where users can create profiles, share posts, interact with other users, and build connections.

## 🚀 Features

- **User Profiles:** Display user information and profile statistics.
- **Create Posts:** Share thoughts and updates with the community.
- **Comments:** Interact with posts by adding comments.
- **Like System:** Like and unlike posts.
- **Follow System:** Follow and unfollow other users.
- **Responsive Design:** User-friendly interface for desktop and mobile screens.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Database:** SQLite

## 🎯 Project Objective

The objective of this project is to gain practical experience in full-stack web development, including frontend design, backend development, database management, and connecting user interactions with server-side functionality.

## 📌 Project Status

Currently, the frontend interface and basic interactive features have been developed. Backend integration, database persistence, and user authentication are planned as the next development steps.
